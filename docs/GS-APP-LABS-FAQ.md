# Kombos — FAQ / Συχνές ερωτήσεις

**Focus / Αντικείμενο:** AI workflows / Ροές τεχνητής νοημοσύνης

## Where do I download it? / Πού το κατεβάζω;

[Latest stable published release](https://github.com/gs-applabs/Kombos/releases/latest). Select the official installer and matching SHA-256 file if provided. Read the requirements, limitations and upgrade notes. A hash is an integrity check, not a signature or proof of safety. Do not bypass OS warnings.

## How do I get started? / Πώς ξεκινάω;

Configure the provider locally and review privacy and credential handling before submitting a prompt.

## What are the limitations? / Ποιοι είναι οι περιορισμοί;

External AI providers may require credentials, separate fees and usage limits. / Οι εξωτερικοί πάροχοι μπορεί να απαιτούν κλειδιά, χρεώσεις και όρια.

## Where do I find screenshots? / Πού βρίσκω εικόνες;

[Actual Windows CI screenshot gallery](product-snapshots/README.md). Some views use demonstration data. Visual tests are not full functional acceptance tests.

## Can I report a bug or suggest a feature? / Μπορώ να αναφέρω σφάλμα ή να προτείνω δυνατότητα;

[Open an issue](https://github.com/gs-applabs/Kombos/issues/new/choose). Include your app and Windows versions and steps to reproduce. Redact personal data, credentials and confidential files.

## What is planned? / Τι σχεδιάζεται;

Clear provider configuration and permission boundaries; demonstrations using local or sample data.

This is a non-binding direction, not a promised release date. / Ενδεικτική κατεύθυνση, χωρίς δεσμευτική ημερομηνία.
